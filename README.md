# Codex Quota Monitor

- macOS 메뉴 막대·노치용 Codex 계정 사용량 확인 앱

![현재 UI 예시 — 계정 도넛·할당량·토큰 기여량·활동·초기화 갱신](resource/images/app-example.png)

- 현재 앱 UI를 예시 계정·사용량으로 렌더링한 화면
- 화면의 이메일·경로·사용량·세션 정보는 예시 데이터

## 주요 기능

### 사용량 UI

- 메뉴 막대·노치에서 최대 4개 Codex 계정의 남은 할당량 확인
- 중앙 숫자: 5시간 할당량 잔여율 / 외곽 링: 주간 할당량 잔여율
- 계정 클릭 시 상세 화면에서 두 할당량·초기화 시각·남은 시간 확인
- 노치 도넛의 소진 구간: 최초 실행·자동 갱신·수동 갱신에서 동일한 짙은 회색
- 주간 잔여량 0%인 경우 흰색 링 표시
- 새로고침 중 마지막 할당량·도넛 크기 유지
- 작은 화면에 맞춘 상세 팝오버 크기 조정 및 세로 스크롤
- 구독 등급별 한글 뱃지와 등급 색상 표시, Go 명칭 유지

### 세션 활동

- 로컬에 기록된 Codex CLI·Codex App 작업의 최근 활동 확인
- 계정별 세션 제목·상태 표시 및 활동 알림
- 표시 계정 순서에 맞춘 알림 위치 및 숨김 계정 알림 제외

### 토큰 사용량

- Codex CLI가 로컬에 저장한 세션 기록(`CODEX_HOME/sessions`)의 토큰 정보 집계
- 서버 실시간 조회가 아닌 로컬 기록 기준
- 최근 12주 일별 사용량을 잔디 형태로 표시
- 오늘·최근 7일·최근 30일의 입력·출력 토큰 확인
- 업데이트 버튼으로 사용량 다시 조회
- 계정별 최신 집계 결과의 SQLite 저장 및 앱 재실행 후 복원
- 마지막 성공 업데이트부터 14일 보관, 재업데이트 시 결과 교체·보관 기간 연장
- 계정 경로 변경 시 해당 계정 기록만 제거, 다른 계정 기록 유지

### 할당량 초기화 갱신

- 상세 화면의 `초기화 갱신` 버튼으로 최소 Ping 요청 실행
- Ping 성공 후 최신 5시간·7일 할당량과 초기화 시각 재조회
- 실행 결과·사용 토큰·초기화 시각 변화 표시
- 서버의 초기화 시각을 확인하는 기능이며 초기화 시각 변경 보장 없음
- 실제 요청에 따른 사용량 발생 가능

### 설정

- 개인 로컬 환경에 맞는 계정별 경로 지정
- 계정별 표시 ON/OFF 및 표시 순서 변경
- 활성 계정을 왼쪽부터 최대 두 개씩 배치, 전체 숨김 시 메뉴 막대 톱니바퀴 제공
- 자동 새로고침 주기·활동 알림 표시 시간·계정 라벨 표시 설정
- macOS 로그인 시 자동 실행 설정

## 계정 설정과 요구 사항

- 최대 4개 계정 등록
- 설정에서 계정별 `CODEX_HOME` 경로 지정 및 표시 계정·순서 선택
- macOS 14 이상, Swift tools 6.0 지원 환경
- 별도 설치·로그인한 실행 가능한 Codex CLI 필요

## 빌드·테스트·패키징

- 저장소 루트에서 실행

```bash
swift build
swift test
scripts/package_app.sh --output /path/to/CodexQuotaMonitor.app --configuration release
open /path/to/CodexQuotaMonitor.app
```

- 로컬 실행용 앱 패키징·임시 서명 제공
- 배포용 서명·공증 미제공
